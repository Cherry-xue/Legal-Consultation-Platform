# 争议材料交接与整理清单（虚构测试文本）

文档编号：CX-TEST-005  
业务范围：诉讼程序  
版本：内部整理示例 V1

本文件描述虚构案件材料的整理计划，不是法院立案指南，不包含法定期限或程序规则。清单中的“完成日期”只是内部工作安排，不代表任何法律期限。

## 第一项 案件事实时间轴
测试案件为星河研学服务中心与青禾教学设备工作室之间的设备交易争议。内部整理人员计划于2027年4月8日前完成事实时间轴。每个事件至少记录日期、参与方、事件摘要、对应材料编号以及尚待确认的问题。例如，合同签署对应材料A01，首次付款对应A02，交付沟通对应A03。无法确认准确日期的事件，应明确标记“日期待核实”，不得根据聊天截图在文件夹中的排序自行推断。

## 第二项 主体与授权材料
主体材料目录用于记录双方准确名称和可核实的主体信息。当前文件仅列出虚构名称，没有统一社会信用代码、住所地或实际经营地。若由工作人员代为沟通或准备材料，还需核对授权范围。业务联系人、签约人和公司负责人可能不是同一人，整理时应分别记录。本文件未对任何人是否具有诉讼代理资格作出判断，也没有提供可直接提交的授权委托书。

## 第三项 合同与付款材料
合同类材料按版本区分为草稿、已签署文本及补充确认记录。A01为设备采购合同的已保存版本，A02为人民币一万八千元预付款的银行回单。回单内容应与合同约定收款主体比对，避免仅凭转账金额就认定特定债务已履行。若存在退款或后续付款，应在清单中追加条目，并记录与原交易的对应关系。当前材料没有后续付款凭证，不能假设全部合同价款已经支付。

## 第四项 交付与质量争议材料
A03为交付时间沟通记录，A04为设备签收清单，A05为安装后运行问题的视频目录。签收清单应与验收记录分开存放，因为收到包裹与完成质量验收是不同事实。视频目录需列出文件名、拍摄日期、设备编号、时长及原文件存储位置。设备是否存在质量问题、问题产生原因和是否达到解除条件，均有待进一步核实，不在本清单中直接下结论。

## 第五项 诉求与计算底稿
整理人员暂列三个待讨论事项：是否继续要求交付、是否协商解除未履行部分、是否提出返还相关预付款。每项拟提出的金额，应能够指向付款凭证、合同条款和计算过程。已支付款项不当然等于最终应返还金额，计算还需要核对已履行部分、退款情况及双方约定。本文件没有计算诉讼费、保全费用、利息或违约金，不应根据清单自动生成确定的缴费通知。

## 第六项 材料真实性与备份
电子文件应保留原始版本，整理副本可以另行命名。截图材料需记录来源、导出方式和形成时间，连续聊天应保留上下文。证据目录和文件内容之间应可以相互定位，避免目录写着A05而实际打开另一份视频。纸质材料可以扫描备份，但是否需要核对原件应结合实际程序另行确认。涉及个人信息的分享副本应适当遮蔽，原始完整材料应妥善保存。

## 第七项 尚未确定的程序问题
拟受理法院、管辖依据、法定起诉条件、时效、举证期限、线上提交入口和是否申请财产保全，均未在本材料中确定。用户询问这些问题时，应明确本资料无法直接回答，并指出需要结合主体所在地、履行地、合同约定、争议性质及真实时间线核实。内部目标日期4月8日不得被回答成法定最后起诉日。
