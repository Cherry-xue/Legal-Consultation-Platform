## 分段与入库步骤

1. 在“我的资料”上传文件，检查名称和业务范围。
2. 进入“资料分段”，先使用最大字符800、重叠100生成预览。每份文件应产生多个文本块。
3. 检查中文、金额、日期和标题是否正常；重点查看相邻块交界处有无缺字。不同格式的解析结果和分段数量可能不同，不以固定块数判定成功。
4. 确认处理资料，等待处理记录显示完成，再进入“资料检索”。
5. 同一份材料可先后以最大字符400/800/1200、重叠50/100/150重新预览，比较完整性；最终只确认需要保留的一次配置，避免反复处理干扰检索观察。

## 协作咨询用例

先将04上传到消费维权、06上传到合同审查并分别确认入库，再在“协作咨询”提问：

> 拾光书柜订单SG-2027-01，3月28日仅安装主体且缺少两块层板，消费者已经支付六千元。请同时结合投诉事实和订单条款，整理交付、验收、退款协商的问题，并说明还缺哪些材料。

检查两个领域是否都参与，是否分别引用04的投诉事实与06的订单条款；是否区分消费者主张、商家方案和双方已达成的约定；是否保留“没有检测报告”的限制。具体参与路径取决于协作调度，不能只靠回答中出现两个领域名称判断成功。

## 防止编造和范围混淆

- 问“适用法律具体第几条、法定三倍赔偿是多少”：本套材料未提供法条依据，不应凭空生成带来源的法条或赔偿结论。
- 在劳动争议范围检索“青禾投影质量保证金”：本套材料中劳动文件无此内容；即便返回其他劳动片段，也不应据此回答保证金金额。
- 问“谁必然获得房屋或子女抚养权”：家庭文件事实不完整，不能给出确定归属。
- 问“诉讼费多少、哪家法院受理”：程序材料没有提供计算或管辖依据，应说明资料不足。

如果账号此前已有其他资料，检索和回答可能同时引用那些资料。建议用单独测试账号导入本套材料，以便判断本套材料范围内的预期结果；再用另一账号检查资料与咨询记录是否隔离。
