## 切分与检索步骤

1. 上传后检查解析结果，再以最大字符800、重叠100生成预览，确认标题、日期、金额和相邻片段正常。
2. 等待入库完成，进行检索；可另试400/50，比较同一问题的证据完整性。块数不是固定验收标准。
3. 在对应业务智能体进行问答。下面检查的是事实和引用，不预设法律效力结论。
4. 协作问题需先上传12、13两份资料，再进入协作咨询。答案应区分单位合同关系与员工工资关系，不重复计算同一笔钱。
5. 测低相关过滤时，最好另用一个普通测试账号，只上传14。避免同账号的其他私人资料影响观察；公共资料仍可能参与检索，因此不能一概要求所有法律问题都返回空结果。
