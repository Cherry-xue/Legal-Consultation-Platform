# 混合检索、重排序和相关性过滤

实现日期：2026-10-28。所有业务 Agent、协作子 Agent 和资料检索页共用后端 `rag.retrieve`，无需重新上传或重建已有向量。

## 实现

1. **权限筛选**：先限定当前账号私有资料、公共资料、适用业务范围和已生效索引版本；关键词语料与 IDF 只使用这些已授权文本块。
2. **两路召回**：向量召回默认30条；词法召回使用中文二元/三元字串及英文数字词的 BM25，默认30条。它不是分词模型或 MySQL 全文索引。
3. **融合**：按排名使用 RRF（常数60）融合、去重；明确条号增加独立精确召回，支持中文/阿拉伯数字及“条之一”等形式。
4. **重排序**：使用确定性特征评分，综合语义相似度、BM25、关键词覆盖、RRF及条号/法名匹配。语义权重保持主导，关键词独立强匹配另设可用分支，避免小知识库因 IDF 较小而无法命中。此版本不是外部神经重排序模型，也不增加重排序模型调用。
5. **过滤**：普通向量候选须满足距离门槛；强词法匹配或准确条号可以独立入选。之后应用最低重排分数，不足 top_k 时不补入弱结果。明确法名和条号的查询不能由其他法或正文中的交叉引用冒充对应条目。
6. **发布前复核**：候选再次核对所属文档、账号权限、删除状态和有效预览版本。返回原文、位置、版本和排名特征，排名分数不是正确率或法律置信度。

向量服务异常时允许可靠关键词结果继续返回，标注 `retrieval_degraded`，检索页和模型回答均提示降级；若词法也没有可靠候选，则报告服务异常，避免把基础设施故障伪装成“知识库没有资料”。

正常检索但所有候选被相关性过滤时，问答返回结构化 `no_basis`、记录运行结果并跳过生成模型；这与向量服务故障导致的检索异常有明确区别。

## 配置

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| RAG_HYBRID_ENABLED | true | 关闭后使用原向量检索，便于对照和回退 |
| RAG_CANDIDATE_LIMIT | 30 | 每路召回预算 |
| RAG_MAX_VECTOR_DISTANCE | 0.5 | 普通向量候选的余弦距离上限 |
| RAG_MIN_LEXICAL_COVERAGE | 0.28 | 强关键词匹配所需的查询词覆盖下限 |
| RAG_MIN_RERANK_SCORE | 0.20 | 最低重排分数 |

阈值是当前模型与语料下的初始配置，不是通用常量。余弦距离越小越相近，重排分数越大越优先，两者不能混用。范围、权限及原文引用检查不能通过这些参数绕过。

## 真实服务对照

脚本 `scripts/compare_retrieval.py --live`：新建独立临时普通账号，在同一批公共法规和同一查询向量上比较策略，不调用生成模型。结束后清理临时账号和检索日志。

最终报告：`data/eval-reports/retrieval-comparison-20261028-201904.json`。

| 指标 | 原向量检索 | 最终混合检索 |
| --- | --- | --- |
| 50道正向题，前5条命中目标条款 | 50/50 | 50/50 |
| 首位命中目标条款 | 49/50 | 49/50 |
| MRR（只在前5条内计算） | 0.99 | 0.99 |
| 问候查询返回数量 | 5 | 0 |
| 无关航天技术查询返回数量 | 5 | 0 |
| 不存在的民法典条号查询返回数量 | 5 | 0 |

首两次试验存在关键词权重使首位排序退步的问题，调整记录分别保存在201431、201713两份同名前缀报告中。最终参数在这批开发题上调节过，结果不能作为独立留出集验证，也不能外推为所有无关问题均会正确过滤。本轮主要收益是保留正向召回、增加关键词补召回和减少明显无关返回，没有证明整体召回率或法律正确率提升。

## 测试和限制

已覆盖：数字条号归一化、子条号区分、双路均遗漏时的精确条号补召回、关键词弥补向量遗漏、BM25长度归一化、跨法/交叉引用误匹配、弱结果过滤、多信号排序、跨账号隔离、向量异常降级、降级无匹配返回错误。

最终后端测试46项、前端测试13项通过，前端构建通过。真实问答冒烟报告 `data/eval-reports/legal-baseline-20261028-202119.json` 中，10次正向检索均命中目标条款，5次问答均完整完成并引用目标条款；其中一次无依据题最初走了旧的异常分支，补齐结构化无依据处理后专项复测报告 `legal-baseline-20261028-202247.json` 中两题均为无依据回应。这不是新版本50题生成回答的全量复测。

当前关键词召回从已授权 SQL 文本块构建评分，词项缓存有容量限制，但仍需扫描授权语料；适合现阶段数据规模，尚未做大规模索引或高并发压测。重排序属于可解释特征排序，不包含神经交叉编码器。过滤只判断片段相关性，不判断事实是否充分、法规是否现行或回答是否语义正确。
