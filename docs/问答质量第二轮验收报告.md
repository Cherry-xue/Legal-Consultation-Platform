## 本轮改进

1. 提示词要求直接回答本题，保持用户已限定的事实前提，不因检索到相邻条文就扩展无关分支。
2. 引用修复仍最多一次，逐字摘录、来源ID和条号检查标准不变。
3. 修复后仍有错误时，逐项核对并移除不合格说明；其余合格说明以“部分完成”发布，并明确告知有内容被移除。全部说明不合格则不发布结论，提示生成引用未通过核对，避免误说是知识库一定缺资料。
4. 协作汇总能够保留子任务中校验通过的部分结果，不把它误记为完整完成。
